## 2. 如何使用

### 2.1 启动

```bash
cd c:\ysy\lerobot\edp-web
npm install
npm run dev
```

浏览器访问：**http://localhost:5173**

### 2.2 建议体验路径（5 分钟）

1. **平台总览**：看 KPI、漏斗、近 7 日曲线、GPU 卡片、事件流  
2. **数据采集**：点进某个任务看切片进度  
3. **生产任务**：对失败 Job 点「重试」  
4. **质检工作台**：对 `black_pen_to_wooden_stand` 点通过/驳回  
5. **LeRobot 交付**：查看 pen / mouse 数据集 frames、episodes、任务文案  

### 2.3 与本地数据的关系

| 本地目录 | 在平台中的位置 |
|----------|----------------|
| `public/datasets/ds-pen`（原 black_pen…/lerobot_data） | 交付 `ds-pen`、质检绑定 `dr2` |
| `public/datasets/ds-mouse`（原 black_mouse…/lerobot_data） | 交付 `ds-mouse`、质检绑定 `dr4` |

当前读取的是 **写死在 mocks 里的元信息**（与真实 `info.json` 一致），尚未在浏览器内直接解析 parquet。

## 5. 维护责任边界（给 Vue 同学）

| 你想做的事 | 改哪个文件 | 风险 |
|------------|------------|------|
| 改看板数字 | `mocks/data.ts` | 低 |
| 改菜单名 | `components/AppLayout.tsx` | 低 |
| 加新页 | `pages/` + `App.tsx` + 菜单 | 中 |
| 接 FastAPI | `api/client.ts` + `.env` | 中（先对齐字段） |
| 大改总览布局 | `pages/DashboardPage.tsx` | 中高 |
| 升级依赖 | `package.json` | 高，改后务必 `npm run build` |

详细对照见：`docs/Vue开发者维护指南.md`。

## 7. 已知限制

1. Mock 数据刷新浏览器后重置（质检结果不落盘）。  
2. Worker / 事件流为模拟刷新，非真实 WebSocket。  
3. 未内嵌三路相机播放；需本地打开 mp4。  
4. `/admin` 路径未单独做；入口为 `/`（需要可加重定向）。
